# Бухгалтерская рабочая область (Grok Bot)

Фреймворк онбординга: один репозиторий 1C OData KZ + один `.xlsx` → MCP, проверка связей, агенты по юрлицам и WhatsApp.

## Что внутри

- `SKILL.md` — скилл для агента Grok Bot ([Бухгалтерская рабочая область](sand-workflow:…))
- `templates/bases-and-contacts.template.xlsx` — шаблон баз и контактов WhatsApp
- `templates/WhatsApp-1C-kontakty.example.xlsx` — пример таблицы маршрутизации

## Как пользоваться в Grok Bot

1. Скажи главному агенту: «подними по фреймворку» и дай URL этого репо + заполненный `.xlsx` (пароли только через секрет/форму, не коммить).
2. Агент клонирует/собирает `1c-odata-mcp-kz`, ставит MCP на каждую базу, проверяет `health`/`capabilities`.
3. Создаёт агента на каждое юрлицо: **«Название (БИН/ИИН)»**.
4. Поднимает WhatsApp (Green API), webhook-рутину и таблицу контактов.

## Важно

- MCP общие на аккаунт; изоляция — в описании агента.
- В WhatsApp и в 1С (запись) — только после явного «да».
- Не коммитьте пароли и токены в git.
